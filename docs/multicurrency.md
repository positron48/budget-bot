# Валюты операций

Изменение 17.10.2026; полный план бюджета: `../../budget/docs/tasks/budget-multicurrency.md`.

Без указания валюты используется RUB; существующая явно сохранённая пользовательская валюта по умолчанию сохраняет приоритет. Явная валюта сообщения всегда приоритетнее настройки. Валюта отображения веб-интерфейса не влияет на ввод бота.

Поддерживаются `20 евро продукты`, `20€ продукты`, `€20 продукты`, `$20 такси`, `20 usd такси`, `20USD такси`, `20 долларов такси`, `100 рублей кофе`, `100руб. кофе`, дроби с запятой/точкой. Русские словоформы доллара/рубля и «баксы» нормализуются. Символы GBP/JPY и отдельные ISO-коды сохраняют прежнюю поддержку. Валюта не извлекается из частей слов. Несколько разных валют в одном сообщении отклоняются с предложением указать одну валюту.

Десятичная сумма `12.05 EUR` без отдельной суммы не считается датой. Дата может стоять до или после отдельной суммы: `12.08 20 евро такси`, `20 евро такси 12.08`.

Парсер передаёт исходную валюту в существующие ручной/LLM пути выбора категории, состояния и gRPC CreateTransaction. Конвертацию выполняет backend бюджета на дату операции. Изменения протокола бюджета обратно совместимы; боту для валютного ввода не нужны новые поля display_amount/target_currency_code, его существующие protobuf-клиенты продолжают работать.

Проверки: `go test ./internal/bot ./internal/grpc`, `go build -tags withgrpc -o /tmp/budget-bot-multicurrency ./cmd/bot`. Новые сценарии — `internal/bot/multicurrency_test.go`. Развёртывание — отдельно после публикации backend, сохраняется обычный CI/Flux процесс.

Предрелизная проверка выявила старый конфликт таймаутов: Telegram ожидал long poll 30 секунд, SOCKS HTTP transport завершал ожидание заголовков через 20 секунд. HTTP timeout теперь равен интервалу polling + 30 секунд (минимум 30), ResponseHeaderTimeout на 10 секунд меньше общего timeout и всё равно больше интервала polling. URL сетевой ошибки маскирует токен до передачи ошибки библиотеке/логгеру; исходная сетевая причина сохраняется. Это предотвращает ложные ошибки ожидания и вывод токена в логах.
